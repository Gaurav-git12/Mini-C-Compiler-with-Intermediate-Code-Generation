Mini C Compiler with Intermediate Code Generation

This project is a mini compiler for a C-like programming language implemented in C++. 
It demonstrates the core phases of a compiler including lexical analysis, syntax analysis, semantic analysis, symbol table management, 
and intermediate code generation.

The system processes source code step-by-step, identifying tokens, validating syntax, checking semantics, and generating three-address code (TAC).
It also includes a web-based interface for visualizing compilation stages and outputs.
